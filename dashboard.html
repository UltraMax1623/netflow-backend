      Help & integrations

      Analysis runs locally with Zeek and packet decoding. No external threat-intelligence service is configured and captures are not sent to one. Chart.js, Cytoscape, fonts and styling load from public CDNs.

      Upload PCAP/PCAPNG or select a live adapter. Live capture uses short windows and pauses during analysis. All charts and the assessment cover the latest capture only. Graph filters affect only the graph.

      Click a graph card or connection for readable evidence. Raw JSON is optional. Red indicates a high-priority heuristic or a processing error; amber indicates a review item or incomplete coverage; green means no configured indicators were found.

      Use a known normal capture to choose a baseline in Settings. Low TCP completion, conflicting ARP/DNS, and repeated SSH connections need investigation; they do not prove an attack. TTL changes and HTTP volume alone are not sufficient evidence.

      Useful Wireshark display filters
      • DNS queries: dns.flags.response == 0
      • DNS responses: dns.flags.response == 1
      • Domain: dns.qry.name == "bank.example"
      • DNS ports: udp.port == 53 or tcp.port == 53
      • SSH: ssh or tcp.port == 22
      • Initial SYN: tcp.flags.syn == 1 and tcp.flags.ack == 0

      The live filter field uses capture-filter syntax instead, for example port 53 or tcp port 22.
